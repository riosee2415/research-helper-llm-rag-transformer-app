# PRD: Research RAG — 전문 연구자용 논문 Q&A

## 목표
석사·박사 연구자가 논문·특허 PDF에 대해 정확하고 출처가 명확한 전문 답변을 대화형으로 받을 수 있는 RAG Q&A 시스템.

**핵심 원칙**: 잘못된 정보 제공 절대 금지. 근거 없는 답변보다 "해당 내용 없음"이 낫다.

---

## 사용자

**대상**: 기술 분야 석사·박사 연구자

**특성**:
- 논문의 특정 수치, 방법론, 실험 조건, 결과를 빠르게 확인하는 용도
- 전문 용어와 기술 표현을 그대로 사용하여 질문
- 연속 질문으로 세부 내용을 파고드는 방식
- 오답에 매우 민감: 출처 없는 답변보다 "모름" 응답이 선호됨
- 로그인 불필요. 단일 PC에서 지속적으로 사용하며 과거 대화를 참고함

---

## 핵심 기능

### F1: PDF 배치 인제스트
- rag_data/ 폴더의 **모든 PDF 파일** 파싱·청킹·임베딩·Pinecone 업로드
- 파일명은 규칙적이지 않아도 됨. rag_data/ 내 모든 .pdf 파일(하위 폴더 포함) 처리
- 파일 MD5 해시 기반 멱등성: 동일 파일 재실행 시 건너뜀
- 파일 단위 독립 처리: 한 파일 실패가 전체 중단을 유발하지 않음
- 스캔본 PDF(텍스트 레이어 없음) 자동 감지 및 경고

### F2: 대화형 전문 QA
- 2-chain RAG: 질문 응축(Chain-1) → 벡터 검색(임계값 0.7) → 전문 QA(Chain-2)
- 세션 내 대화 히스토리 유지 (MAX_MEMORY_TOKENS 초과 시 오래된 메시지 트리밍)
- 유사도 임계값(0.7) 미달 시 "관련 내용 없음" 응답 (Chain-2 미실행)
- 검색된 컨텍스트에 없는 내용 생성 금지 (할루시네이션 방지)

### F3: 출처 표시
- 모든 답변에 근거 청크 표시: `(출처: 파일명.pdf, p.N)`
- 사용자가 원문 청크를 펼쳐볼 수 있는 expander UI
- 출처 없는 내용이 답변에 포함되지 않음

### F4: 대화 초기화
- 사이드바 버튼으로 현재 대화 및 RAGEngine 메모리 초기화
- 초기화 시 로컬 세션 파일도 함께 삭제

### F5: 로컬 세션 영속화 (로그인 없음)
- 대화 히스토리를 PC 로컬 파일(`data/sessions/`)에 자동 저장
- 앱 재시작 시 가장 최근 세션 자동 복원 (메시지 표시 + RAGEngine 메모리 재구성)
- 사이드바에 과거 세션 목록 표시 (날짜·시간 기준)
- 과거 세션 선택 시 해당 대화 내용 열람 가능 (읽기 전용, 이어서 질문 불가)
- 현재 세션 (활성 대화)은 실시간 자동 저장

## 비기능 요구사항

| 항목 | 목표값 |
|------|--------|
| 응답 시간 | 30초 이내 (일반 질문, 스트리밍 미사용) |
| 인제스트 속도 | 10페이지 PDF 약 5초 |
| 인제스트 멱등성 | 동일 파일 재실행 시 Pinecone 상태 변화 없음 |
| API 재시도 | OpenAI 오류 시 지수 백오프 최대 3회 (1s, 2s, 4s) |
| 에러 가시성 | 모든 에러는 한국어 메시지로 사용자에게 표시 |
| 최소 청크 길이 | 100자 미만 청크는 인덱싱 제외 |
| 메모리 한도 | 대화 히스토리 4000 토큰 초과 시 오래된 메시지 자동 트리밍 |
| 세션 저장 | 질문/답변 발생 즉시 로컬 파일에 자동 저장 |
| 세션 복원 | 앱 재시작 후 5초 이내 최근 세션 복원 |
| 로깅 | 모든 에러·경고는 파일(logs/app.log)과 콘솔에 동시 기록 |

## 에러 시나리오 요구사항

상세 처리 방법은 ERROR_HANDLING.md 참조.

| 에러 | 동작 | 사용자 메시지 |
|------|------|--------------|
| PDF 파싱 실패 | 해당 파일 스킵 | "에러: PDF 파싱 실패: {filename}" |
| 스캔본 PDF | 감지 후 스킵 | "경고: 스캔본으로 판단됨: {filename}" |
| 비어있는 PDF | 스킵 | "경고: 페이지가 없는 PDF: {filename}" |
| 유효 청크 없음 | 스킵 | "경고: 유효한 청크 없음: {filename}" |
| OpenAI API 오류 (재시도 소진) | UI에 에러 메시지 | "AI 서비스 오류. 잠시 후 다시 시도해 주세요." |
| Pinecone 연결 실패 (앱) | 입력창 비활성화 | "RAG 엔진 초기화 실패. 연결을 확인하세요." |
| 검색 결과 없음 (임계값 미달) | answer에 포함 | "제공된 문서에서 관련 내용을 찾을 수 없습니다." |
| 빈 LLM 응답 | 1회 재시도 후 에러 | "답변 생성 실패. 다시 시도해 주세요." |
| OpenAI API 키 무효 | 즉시 종료 | "OpenAI API 키가 유효하지 않습니다. .env를 확인하세요." |
| Pinecone API 키 무효 | 즉시 종료 | "Pinecone API 키가 유효하지 않습니다. .env를 확인하세요." |
| Pinecone 인덱스 없음 | 즉시 종료 | "Pinecone 인덱스 'resercher-helper'가 존재하지 않습니다." |
| 환경변수 없음 | 임포트 시 즉시 에러 | "환경변수 {VAR}가 설정되지 않았습니다." |
| 세션 파일 읽기 실패 | 빈 세션으로 시작 | "이전 세션을 불러올 수 없어 새 세션으로 시작합니다." |
| 세션 파일 저장 실패 | 경고 로그, 대화 계속 | (사용자에게 표시 안 함, 로그만) |

## MVP 제외 사항

- 사용자 인증 / 로그인 (로컬 세션으로 대체)
- 브라우저 파일 업로드 UI (CLI 인제스트만 지원)
- 다국어 답변 (한국어 고정)
- 문서 관리 UI (추가·삭제·목록 조회)
- 스트리밍 답변 (응답 완성 후 일괄 표시)
- 답변 평가·피드백 기능
- OCR (스캔본 PDF 텍스트 추출)
- 문서별 검색 필터 (전체 인덱스 통합 검색)
- Reranking (검색 후 재순위화)
- 수식·표 구조 보존 (텍스트 추출 기반 처리)
- 과거 세션 이어서 질문 (읽기 전용 열람만 지원)
